# Tech stack

- TypeScript Worker on Cloudflare Workers (wrangler), Node >=24, pnpm (version in `packageManager`).
- State: KV (`DEMO`), Durable Object `DailyLimits`, queue `pointsman-demo-bridge` with a dead-letter queue nothing reads.
- Tests: vitest with `@cloudflare/vitest-plugin` (`test/*.test.ts`); `worker-configuration.d.ts` is generated by `wrangler types` and git-ignored.
- The page has no build step; MapLibre GL JS comes from unpkg, so the CSP in `site/_headers` must allow it.
- No lint or format tool is configured.
